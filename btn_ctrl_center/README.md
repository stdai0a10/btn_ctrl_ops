# `btn_ctrl_ops/btn_ctrl_center`

For [btn_ctrl_center](https://github.com/stdai0a10/btn_ctrl_center)

## Quickstart

0. Ensure `btn_ctrl_center` services are running.
1. Copy the file `.env` from the project `btn_ctrl_center` to this folder and rename it to `.env.docker`
2. Update the variables in `.env.docker`.
3. Copy the example file `.env.example` to `.env` and update it.
4. Run `docker compose up -d --build`.
